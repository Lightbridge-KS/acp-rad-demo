## Confirmed contracts

- **Slice 6:** (a) **The gate is a reducer with declarative effects** (`qaGate.ts`): `start · turn_end · timeout · review · override · dismiss` → `prompt("/qa") · cancel · transition · audit`; the Workspace executes effects and feeds `turn_end` from `AgentPort.prompt`'s resolved stop reason. Flags "raised during the turn" = `flags.list().slice(countBefore)` — never compare `f{n}` ids as strings. Late or foreign `turn_end`s are no-ops. (b) **Refusal precedes proposal**: `onUpdate` turns a `tool_call` diff into a proposal *before* `request_permission` arrives, so a lock must be checked there too, not only in the handlers; the one predicate is `refuseReason()`. A refused permission is answered with the agent's *reject* option (kind `reject_once`), never `cancelled`. (c) **deepagents-acp already does model switching**: `AgentServerACP(models=[{value, name}])` → `session/new.configOptions` `model` select; `session/set_config_option` validates, stores `_session_models[session]`, calls `_reset_agent` → the factory gets `context.model`; the graph (and its `MemorySaver`) is rebuilt — a switch mid-turn would swap the agent under the running prompt, so the select is disabled while running. TS SDK 1.4.0: `acp.methods.agent.session.setConfigOption`, responses are not zod-parsed so `configOptions` survives; narrow `type === "select"` before reading `currentValue`. (d) **A zero-hunk write must not pend**: `ProposalStore.add` registers it `applied` (an idempotent `/template` used to leave a phantom pending proposal). (e) **`AuditLog.setActor` lives in its own field** — `bind` replaces `ctx` wholesale; queued records carry the actor they were made under. (f) **Template blanks are `__` as well as `____`** (`__ hours`); `E_V_M_` has single underscores — match `_{2,}`. `ct-brain-er-blank` loads as `"\n"`, so the gate needs an *empty* blocker. (g) **Per-case state resets by remount**: `App` (shell: fixture, role) + `Workspace key={fixture.id}`; the shell injects `headerStart` / `banner` and reads `dirty()` / `cancel()` through a ref; never `window.confirm` (it blocks the Chrome tool and the page). (h) Ops: keys in a root `.env` (`.env.example`), `RAD_MODELS` for the switch; `lb key run` is personal tooling and stays out of the repo docs. Chrome tool: screenshot scale changes between frames — click by `find` refs, drive `<select>`s with `form_input`.
- **Slice 5:** (a) **`_rad/flag` is acknowledged by the Client on receipt** (KS): the store holds the flag and the line is marked before the response leaves; the radiologist's Acknowledge is local (`flag.acknowledged`); nothing is in flight on Stop; the slice-6 gate counts `FlagStore.open()` at `end_turn`. (b) **Python SDK outgoing extension requests** go through `AgentSideConnection.ext_method("rad/flag", params)` — there is no `send_request` on it; `ext_method` prepends the `_`, returns the raw result dict, raises `RequestError` (error response) / `ConnectionError` (dropped pipe). (c) **A tool that raises escapes the LangGraph loop and kills the `session/prompt` handler** — profile tools return every failure as text (like `backend.py`); a pydantic validation error on the args (e.g. a fifth kind) becomes an error `ToolMessage` the model reads — proven through a real `ToolNode` in a compiled graph (a bare `ToolNode.ainvoke` needs the runtime and fails). (d) **deepagents-acp streams a custom tool** as `tool_call{kind: "other", title: <tool name>, rawInput}` and its returned string as `tool_call_update.content`; the sidebar labels it from `title`, not `kind`. (e) **Line anchoring**: `locations[].line` counts the file *as the agent read it* — served line N = `canonicalLines(file)[N-1]`, and while a grant is open that file is `grant.baseText`; the editor walks the buffer's section range like `canonicalLines` (insert lines skipped, blank runs collapsed) to the ordinal, verifies the text, falls back to a text match never on a blank or label line.
