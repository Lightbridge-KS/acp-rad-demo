## Confirmed contracts

- **Slice 5:** (a) **`_rad/flag` is acknowledged by the Client on receipt** (KS): the store holds the flag and the line is marked before the response leaves; the radiologist's Acknowledge is local (`flag.acknowledged`); nothing is in flight on Stop; the slice-6 gate counts `FlagStore.open()` at `end_turn`. (b) **Python SDK outgoing extension requests** go through `AgentSideConnection.ext_method("rad/flag", params)` — there is no `send_request` on it; `ext_method` prepends the `_`, returns the raw result dict, raises `RequestError` (error response) / `ConnectionError` (dropped pipe). (c) **A tool that raises escapes the LangGraph loop and kills the `session/prompt` handler** — profile tools return every failure as text (like `backend.py`); a pydantic validation error on the args (e.g. a fifth kind) becomes an error `ToolMessage` the model reads — proven through a real `ToolNode` in a compiled graph (a bare `ToolNode.ainvoke` needs the runtime and fails). (d) **deepagents-acp streams a custom tool** as `tool_call{kind: "other", title: <tool name>, rawInput}` and its returned string as `tool_call_update.content`; the sidebar labels it from `title`, not `kind`. (e) **Line anchoring**: `locations[].line` counts the file *as the agent read it* — served line N = `canonicalLines(file)[N-1]`, and while a grant is open that file is `grant.baseText`; the editor walks the buffer's section range like `canonicalLines` (insert lines skipped, blank runs collapsed) to the ordinal, verifies the text, falls back to a text match never on a blank or label line. (f) **`ai-flag` stays out of `withoutOverlayAttrs`** (which `decideHunkOps`'s reject path uses on struck lines) and is looked up with `runs.some` (typing at a line start strips the first run's marks); it is in `NO_MARKS` and `OVERLAY_FORMATS`; `deltaToMarkdown` ignores it anyway. (g) **Skills with a capability dependency** declare `requires: <cap>` in their frontmatter; `advertise(skills, client_caps)` hides them and the tool is passed to `create_deep_agent` only when the client negotiated the capability.
- **Slice 4:** (a) **Local proposals** (editor commands on a non-blank buffer) carry `origin: "local"`: no grant — a grant would make `fs/read_text_file` serve the pre-command buffer for 60 s —, no permission waiter, `accept_edit` coerced to `accept`, excluded from `matchPending` and from `cancelAll` (Stop/close), state → `applied` on decision. (b) deepagents-acp batches **parallel `edit_file` calls under one interrupt**: two `session/request_permission` arrive with the *same* `toolCallId` — correlate by `rawInput`. A proposal the radiologist decides *before* its request arrives stays `decided` with no `options` and is answered (grant included) when the request comes; `matchPending` includes such proposals. (c) **Quill:** never call `quill.getSelection()` from render or a tick-driven effect — it runs `quill.update()`, which can emit a text-change and chain React commits ("Maximum update depth exceeded"). Track the caret from `selection-change` (which Quill reports *before* the model catches up with a keystroke → derive after a macrotask) and from text-change deltas (`caretAfter` for user changes, `transformRange` for api changes); coalesce `setTick` per animation frame. Quill's keyboard module bails on `defaultPrevented`, so a capture-phase `keydown` on the editor container is enough to own ↑↓⏎⇥⎋ while a menu is open. (d) **Skills:** `RadReportAgentServer` sends `available_commands_update` as a task right after the `session/new` response and expands `/name [arg]` in `prompt()`; the editor's sidebar store keeps `{name, description, hint}`; skills are hidden when `level === 0`. (e) **Menus:** the composer's `/` lists skills only — editor commands are not chat (KS, 2026-08-30, amends "the same list on three surfaces"); a typed query collapses the groups into one ranked *Matches* list (exact id · id prefix · id substring · description) so Enter never picks a snippet whose description mentions the query (assistant-ui's own search matches descriptions; the composer wraps the adapter's `search` with the same ranking). (f) `AuditLog` queues records made before `bind` (commands run while connecting) and stamps them once the session exists. (g) `/priors/index.md` is authored per case (design 04 §4) and served verbatim; `meta.json.study.date` is the current study's date. (h) Dev: the dev server must run **outside** the sandbox for Chrome to reach it; the Chrome tool must be pointed at the local browser; `lb key run openai-personal -- just dev` (no `--env`); `just smoke` starts its own bridge — stop `just dev` first or run `node apps/bridge/scripts/smoke.ts` against the running one.
- Bridge framing: one JSON-RPC message per WebSocket frame ⇄ one NDJSON line on the agent's stdio. The bridge never parses ACP.
- `_meta.rad` is the only extension slot on `initialize`, `session/new`, `session/prompt` (ACP v1; no root fields).
- Python SDK (`agent-client-protocol` 0.12.1) **spreads `_meta` contents into handler kwargs** (`acp.utils.model_to_kwargs`): `_meta.rad` arrives as `kwargs["rad"]`, not `field_meta`. Responses carry `_meta` via `field_meta=`.
- `initialize.result._meta.rad.model` is informational (display/audit); the agent reports its `RAD_MODEL`.
- `deepagents-acp` calls the agent factory lazily at the first prompt, not at `session/new`; `session/new` returns no `modes`, so the editor's `set_mode` hygiene is a no-op for it and only fires for registry agents.
- **Level 0 agents (spike 1b; target `claude-agent-acp` first, Gemini second):** a registry agent's permission gating is governed by the *host user's* settings and the model's tool choice, not by the Client. The Client therefore (a) pins `session/set_mode: default` after `session/new` when `modes` is advertised — *built in slice 3*, (b) filters `allow_always` from write permissions (INV-1) — *built*, (c) ignores their `available_commands_update` (host-skill leak) — *slice 7*, (d) learns of edits from the on-disk mirror, not `fs/write_text_file` — *slice 7*. For `claude-agent-acp` the edit `diff` arrives in `tool_call_update.content` *before* `session/request_permission` and the two share a `toolCallId`; deepagents-acp does not (see Slice 3 contracts), which is why the editor also correlates by `rawInput`.
- Unknown `sessionUpdate` kinds (`usage_update`, `config_option_update`) pass through the TS SDK; the sidebar must tolerate them.
- **Slice 3:** (a) deepagents-acp sends the edit `diff` on `tool_call` *before* `session/request_permission`, but the permission request carries a **fresh uuid**, not the tool call id — correlate by `rawInput` (`file_path` + `old_string`/`new_string`). (b) `edit_file` never gets a completion update — a resolved permission ends the card. (c) The backend does read-modify-write; while a grant is open the editor serves the proposal's base text for that path (≤ 60 s) so the agent's edit reproduces what it showed; the write is then `applied` (equals the decided buffer) or `partial`, returned in `WriteTextFileResponse._meta.rad`. (d) Clinical verbs (`accept` / `accept_edit` / `reject`) go on the wire by wrapping the ACP client connection (`PermissionRewritingClient`), mapped back to deepagents' `approve`/`reject`. (e) `BRIDGE_TRACE=1` logs frame methods/ids both ways — the bridge stays a pipe otherwise, except `_rad/audit` persistence.
- **Slice 2:** `session/new._meta.rad.manifest: string[]` lists every readable virtual path (ACP v1 has no `ls`); `ls`/`glob` answer from it, `grep` reads candidates. Converter API is `Op[]`-based (no runtime Delta class; `quill-delta` is a type-only dep) so Quill's Delta and the package never need the same class. Absent section ⇒ absent file ⇒ `-32004` (US-WA has no `technique`). Every `fs/write_text_file` → `-32003` until the proposal flow (slice 3). Parse rule: `**` opens bold only before a non-space, closes only after one; `_` only at word boundaries and never adjacent to `_`; an unclosed opener unwinds to literal text.
